1. الملخص التنفيذي Executive Summary

الفكرة بتحل مشكلة حقيقية وموجودة في السوق: منتجات زي Google CCAI Agent Assist وSalesforce Einstein وZendesk AI Copilot وMicrosoft Copilot for Service بتتباع لنفس الهدف. شركات الاتصالات بتقيس النجاح بـ AHT (متوسط وقت المكالمة)، وFCR (حل المشكلة من أول تواصل)، ووقت تدريب الموظف الجديد، وأخطاء الـ compliance.

المشروع الحالي RAG knowledge assistant قوي في الـ retrieval، لكنه لسه مش agent-assist product: الموظف بيكتب المشكلة بنفسه في شاشة منفصلة، ومفيش customer context ولا memory ولا قنوات ولا tickets. الخطة دي بتقفل الفجوة دي في 3 خطوات، وكل حاجة شغالة على موديلات open-source بننشرها بنفسنا.

النطاق: المشروع ده للتعلّم والـ portfolio: Agent Assist لـ contact center شركة اتصالات واحدة.
الحكم النهائي (Verdict): المشروع ممكن تنفيذه — Feasible بنسبة عالية.
  • تقنيًا: كل الأجزاء ليها بدائل open-source ناضجة (vLLM، BGE-M3، faster-whisper، LangGraph، MCP SDK).
  • العائق الأساسي هو الهاردوير المحلي (RTX 2050، 4GB VRAM) وكوتة الإنترنت. القرار: Local-first. كل خدمة لازم تشتغل الأول على اللابتوب بموديلات صغيرة (≤3B GGUF) ونقيس جودتها وأقصى capacity ليها، وبعد كده ننقل لـ GPUs مجانية (Kaggle/Colab) ثم بحد أقصى $10.
  • العائق التاني هو الداتا: مفيش داتا CRM أو محادثات حقيقية متاحة، فهنعمل synthetic data بجودة مراجَعة يدويًا، ونستخدم صفحات وPDFs حقيقية من مصادر عامة للـ KB.
  • مستوى "production صغير" (20–100 موظف، شركة واحدة) يقدر يوصل لـ ~90% من الـ checklist. الـ 10% الباقية (SSO مؤسسي، تكامل حقيقي مع Siebel/Genesys، شهادات أمان) خارج نطاق الـ portfolio.

2. تقييم المشروع الحالي Current-State Audit

قريت الكود كله: حوالي 3,400 سطر Python في src/، و11 ملف tests، و3 notebooks للـ eval، وUI ثابتة (HTML/JS/CSS ~2,100 سطر).

Strengths ✔

  • Clean layering: controller → service → repository, factories, DI, singletons
  • Multi-format ingestion (HTML, XML, DOCX, scanned/Arabic PDF via OCR, live web)
  • Hybrid retrieval: dense + BM25, RRF, rerank; filters by intent/format
  • Structured JSON output + SSE streaming
  • Langfuse tracing with latency, tokens and cost
  • Real evaluation: ground truth, extraction metrics, RAGAS (AR + EN)
  • Docker Compose + GitHub Actions CI

Gaps ✘

  • UI is a single "type the problem" form — not how CSRs work
  • No customer, ticket, conversation or channel model; no database besides Qdrant
  • No memory (session or customer), no tools/actions, no agent loop
  • Fully tied to paid APIs (Cohere, Gemini); no provider abstraction
  • KB is 10 synthetic docs (~2 MB each, padded) + 4 scraped pages
  • Faithfulness 0.61, Arabic 0.43; judge = same model (biased)
  • No auth, PII masking, audit log, rate limits; CORS *
  • Startup ingestion inside the API process; no job queue

3. المشكلة من ناحية البيزنس How CSRs Really Work

يوم الموظف في الحقيقة

الموظف بيبدأ الشيفت بـ login على الـ agent desktop (Genesys / Avaya / NICE / Salesforce Service Cloud / Zendesk، أو CRM داخلي زي Siebel في شركات الاتصالات المصرية). بيحط حالته "Available"، والـ ACD / routing بيوزّع عليه المكالمات والشاتات والتيكتس حسب المهارة واللغة. لما تواصل يوصل، بتفتح قدامه شاشة فيها بيانات العميل (customer 360): الرقم، الباقة، الرصيد، آخر فواتير، والتيكتس المفتوحة.

الحل الأساسي اللي بيتعمل النهاردة (The naive baseline)

StepBaseline (no AI)Typical timeWith TeleCopilot v2
Understand problemListen / read, ask follow-ups30–90 sLive intent + summary from the transcript
Look up customerClick through CRM tabs, billing system30–60 sTools fetch plan, bills, outages, past tickets automatically
Find the policyKeyword search KB, read a long PDF, ask a team lead60–180 sGrounded answer + citation + next-best-action
Write the replyType or use canned macros30–90 sDraft reply in the customer's dialect, one-click insert
Take actionCreate ticket, apply credit, escalate30–120 sPre-filled action, CSR approves
Wrap-up (ACW)Write notes, pick disposition code30–90 sAuto summary + disposition, CSR confirms
القيمة المتوقعة: تقليل AHT بنسبة 10–25% (أرقام منشورة من vendors زي Google وSalesforce، ومحتاجة تتأكد عندنا بالـ eval)، وأكبر توفير بييجي من الـ after-call work والبحث في السياسات. الموظف الجديد بيبقى productive أسرع، والـ supervisor بيشوف معدل قبول الاقتراحات (acceptance rate) كمؤشر جودة.

ليه الـ Memory مهمة للبيزنس؟

  • Repeat contacts: "دي تالت مرة العميل يشتكي من قطع الـ ADSL الشهر ده" → escalation أو تعويض بدل نفس الخطوات تاني.
  • Handover: العميل كلّم على WhatsApp امبارح والنهاردة بيتصل → الموظف الجديد يشوف الملخص من غير ما يسأل من الأول.
  • CSR feedback: لو الموظف عدّل الرد المقترح أو رفضه، ده بيتسجل ويتحول لداتا لتحسين الـ KB والـ prompts.
