# UI reference

Visual reference: Figma community file "Chat UI"
https://www.figma.com/community/file/1057195320253196766/chat-ui

Style guide: [STYLE_GUIDE.md](STYLE_GUIDE.md). Save the reference screenshot here as `reference-chat-ui.png`.

Direction: keep the calm colours, spacing and clean chat layout; no emojis, no robot/chatbot imagery; a normal,
efficient work tool for CSRs (clear hierarchy, few clicks, readable Arabic RTL).
